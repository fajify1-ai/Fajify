# Milestone 1 — Engineering Foundation

Milestone 1 has **four delivery phases**, executed in parallel with explicit shared contracts.

| Phase | Implementation scope |
| --- | --- |
| **M1-P1 — Backend & Platform** | NestJS API, Postgres/PostGIS foundation, workspace/tooling, integration seams, development environments and verification |
| **M1-P2 — Customer & Frontend** | Flutter customer migration, branding/navigation, shared components, Next.js customer shell and API/Keycloak hooks |
| **M1-P3 — Faji Business** | Flutter Business scaffold, Sign In/Register entry, dashboard, menu/services, orders and reservations mock shells |
| **M1-P4 — Ride, Dispatch & Operations** | Single Flutter Ride & Dispatch application with distinct driver and dispatcher flows; admin web scaffold |

Shared contracts and design tokens should be agreed before duplication. Working live authentication, payments, trips and settlement are outside M1 scaffolding scope. See [four-phase model](FOUR_PHASE_MODEL.md) and [milestone acceptance](../engineering/MILESTONES.md).

Historical PRs, commit attribution, evidence and acceptance files retain original owner/branch labels; they are not retrospectively renamed.
