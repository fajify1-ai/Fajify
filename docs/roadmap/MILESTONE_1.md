# Milestone 1 — Engineering Foundation

**Developer 1 — Backend/platform:** monorepo workspace and tooling, NestJS API foundation, PostgreSQL/PostGIS design, authentication integration seams, development environments and verification.

**Developer 2 — Customer:** import and audit the old Flutter customer app, preserve branding/navigation, develop common Flutter component contracts, and prepare Keycloak/API integration.

**Developer 3A — Business:** scaffold independent Flutter Business app with onboarding, dashboard, reservations, menu/order screen shells; shared theming and auth hooks.

**Developer 3B — Ride & Dispatch:** scaffold independent single Flutter app with Driver and Dispatcher roles, trip/map interface shells, role-aware routing, and auth/API hooks.

Shared contracts and design tokens should be agreed before duplication. Working authentication, live payments, production trips and reservation settlement are **out of scope for initial scaffolding**.
